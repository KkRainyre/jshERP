# Technical Framework
* Core Framework: Spring Boot 2.0.0
* Persistence Layer Framework: Mybatis 1.3.2
* Log Management: SLF4J 1.7
* Frontend Framework: Vue 2.7.16
* UI Framework: Ant-Design-Vue 1.5.2
* Template Framework: Jeecg-Boot 2.2.0
* Project Management Framework: Maven 3.3.9
